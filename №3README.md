Анализатор чисел



1)Назначение проекта:

Консольная программа для комплексного анализа целых чисел. Программа определяет различные характеристики введённого числа, помогая быстро получить всю необходимую информацию о нём.



2)Какие задачи решает программа:

Программа анализирует введённое целое число и определяет:



Знак числа: положительное, отрицательное или ноль

Чётность: чётное или нечётное

Делимость на 3: делится без остатка или нет

Делимость на 5: делится без остатка или нет

Простота числа: является ли число простым

Количество цифр: сколько цифр в числе



Корректная работа с отрицательными числами

Обработка ошибок ввода (защита от букв и символов)



3)Инструкция по запуску:



Необходим язык программирования Python 3.12

сохраняем код в с расширением .py

открываем терминал/командную строку



Выполните команду: python analizator.py



4)Как пользоваться программой:



Запустите программу через терминал

Введите целое число для анализа:

Можно вводить положительные числа: 13, 30, 100

Можно вводить отрицательные числа: -7, -15

Можно ввести ноль: 0

Получите полный анализ числа со всеми характеристиками

Для продолжения введите y (да) или n (нет) для выхода

4

четное: да

делится без остатка на 3: нет
