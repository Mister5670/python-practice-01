Калькулятор стоимости покупки



1)Назначение проекта



Программа для расчёта стоимости покупки с учётом скидок. Позволяет быстро узнать итоговую цену товара при покупке нескольких единиц.



2)Какие задачи решает программа:



Расчёт общей стоимости покупки (цена × количество)

Автоматический расчёт скидки в зависимости от суммы:

&#x20;- 5000–9999 руб. → скидка 5%

&#x20;- 10000–14999 руб. → скидка 10%

&#x20;- 15000+ руб. → скидка 15%

Вывод подробного чека:

&#x20;- Итоговая сумма

&#x20;- Размер скидки в процентах

&#x20;- Скидка в рублях

&#x20;- Итоговая цена к оплате



3)Инструкция по запуску:



Необходим язык программирования Python 3.12

сохраняем код в с расширением .py

открываем терминал/командную строку



Выполните команду: python calculator.py



4)Как пользоваться программой:



Запустите программу через терминал

Введите название товара

Введите цену товара (целое число)

Введите количество товара (целое число)

Программа автоматически рассчитает скидку и выведет чек



5)Пример работы программы:



Товар: Пк

Цена: 150000

Кол-во: 7

Итого: 1050000

Скидка в %: 15%

Скидка в рублях: 157500.0

Итоговая цена: 892500.0
