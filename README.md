# python-practice-01

Учебный проект по Python.

## Функционал

### Базовая версия
Простой калькулятор, который запрашивает 2 числа и вид операции с клавиатуры и выводит результат.

### Новый функционал
- Возможность выполнять несколько вычислений подряд без перезапуска программы.
- После каждой операции программа спрашивает: «Хотите выполнить ещё одну операцию? (да/нет)».
- Обработка некорректного ввода (нечисловые значения, деление на ноль, неизвестная операция).
- Корректная обработка ответа на вопрос о продолжении (принимается только «да» или «нет»).
