Конвертер единиц измерения



1)Назначение проекта:

Простая консольная программа для быстрого перевода величин из одних единиц измерения в другие. Программа позволяет конвертировать температуру, расстояние, массу и длину.



2)Какие задачи решает программа:

Программа выполняет перевод в четырёх направлениях:



Температура: Градусы Цельсия - Градусы Фаренгейта

Расстояние: Километры - Мили

Масса: Килограммы - Фунты

Длина: Метры - Футы



Обработка ошибок при вводе (защита от букв и символов)

Корректная обработка неизвестного выбора



3\) Инструкция по запуску:



Необходим язык программирования Python 3.12

сохраняем код в с расширением .py

открываем терминал/командную строку



Выполните команду: python conventator.py



4)Как пользоваться программой:



Запустите программу через терминал

Выберите тип конвертации из предложенного меню

Введите номер желаемого преобразования (1, 2, 3 или 4)

Введите значение для конвертации (можно с десятичной точкой, например: 36 или 2.5)

Программа покажет результат

Для продолжения введите y (да) или n (нет) для выхода



5)Пример работы программы:

1\. Градус Цельсия -> Градус Фаренгейта

2\. Километры -> Мили

3\. Килограммы -> Фунты

4\. Метры -> Футы
