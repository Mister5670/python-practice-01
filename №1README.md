Консольный калькулятор



1\)Назначение проекта:

Простой консольный калькулятор для выполнения базовых арифметических операций. Программа предназначена для быстрых вычислений прямо в терминале без необходимости открывать отдельное приложение.



2\)Какие задачи решает программа:

Выполнение основных математических операций:



Сложение (+)

Вычитание (-)

Умножение (\*)

Деление (/)

Целочисленное деление (//)

Остаток от деления (%)

Возведение в степень (^)



Обработка ошибок:

Деление на ноль

Неизвестные операции



3\)Инструкция по запуску

Необходим язык программирования Python 3.12

сохраняем код в с расширением .py

открываем терминал/командную строку



Выполните команду: python calculator.py



4)Как пользоваться программой:

Запустите программу

Введите первое число (можно с десятичной точкой)

Введите математическую операцию из списка: +, -, \*, /, //, %, ^

Введите второе число

Программа покажет результат

Для продолжения введите y (да) или n (нет) для выхода



5\)Пример работы программы:

Введите первое число: 4

Введите операцию (+, -, \*, /, //, %, ^): +

Введите второе число: 3

Результат: 7.0

Продолжить? (y/n): n
